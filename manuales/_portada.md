## Cómo usar este manual

Este documento reúne **todos los manuales de procedimientos** de Candela Café &
Patisserie. Está escrito **para la persona que ocupa cada puesto**: si trabajás en un
puesto, lo que necesitás saber para hacerlo bien está acá, aunque el que sabía no haya
venido.

> [!regla]
> ### Leé primero los documentos comunes y después el manual de tu puesto.
> Los documentos comunes valen para todos. El manual de tu puesto tiene lo tuyo y remite
> a los comunes para no repetirlos.

### Cómo se lee

| Si ves… | Significa |
|---|---|
| Un cuadro **rosado** | La regla que resume esa sección |
| Un cuadro **rojo claro** | Algo que no se hace nunca |
| Un cuadro **amarillo** | Una advertencia o un error frecuente |
| Un cuadro **gris** | Algo que todavía falta definir |
| **☐** | Un ítem de checklist |
| *Un nombre en cursiva* | Otro manual de este documento, donde está el detalle |

> [!nota]
> **Si algo de este manual no coincide con lo que se hace de verdad, decilo.** Se
> corrige el manual o se corrige la práctica, pero no se dejan las dos cosas distintas.
